# Day 2 - Decision Making with Conditionals

## Topics Covered

- Comparison operators (`==`, `!=`, `>`, `<`, `>=`, `<=`)
- Boolean values (`True` and `False`)
- `if` statements
- `if/else` statements
- `elif` statements
- Logical operators (`and`, `or`, `not`)

## Projects

- Age Checker
- Temperature Monitor
- Login System
- Motor Speed Monitor
- Engineering Safety Monitor

## Things I Learned

- Programs can make decisions using conditions.
- Comparison operators evaluate relationships between values.
- Boolean expressions return either `True` or `False`.
- `if`, `elif`, and `else` allow programs to execute different code paths.
- Logical operators combine multiple conditions to create more advanced decision-making.
